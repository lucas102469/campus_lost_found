캠퍼스 분실물 서비스 실행 방법

1. 준비
Python 3.10 이상을 설치합니다. 설치 시 Add Python to PATH를 체크합니다.
ZIP 파일은 먼저 압축을 풉니다. 압축 파일 안에서 바로 실행하지 않습니다.

2. 필요한 라이브러리 설치
VS Code에서 app.py와 requirements.txt가 있는 campus_lost_found 폴더를 엽니다.
상단 메뉴의 터미널 > 새 터미널을 열고 아래 명령을 실행합니다.

python -m pip install -r requirements.txt

3. 서버 실행
같은 터미널에서 아래 명령을 실행합니다.

python app.py

4. 접속 및 로그인
브라우저 주소창에 아래 주소를 입력합니다.
http://127.0.0.1:5000

테스트 학번: 2221054, 2221055, 2221056
회원가입과 비밀번호 입력은 없습니다.
서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다.

5. 지도와 경로
지도와 외부 경로 조회에는 인터넷 연결이 필요합니다.
현재 위치 안내가 나오면 브라우저에서 위치 권한을 허용합니다.
습득자가 채팅에서 위치를 공개한 뒤 분실자가 네비게이션을 이용합니다.
truststore는 PC가 신뢰하는 인증서를 이용해 HTTPS 연결을 검증합니다.

6. 데이터 및 사진
첫 실행 시 DB와 세션 키가 instance 폴더에 자동 생성됩니다.
등록 데이터는 DB에, 업로드한 사진은 uploads 폴더에 저장됩니다.
기존 데이터와 사진을 유지하려면 이 폴더들을 삭제하지 마세요.
사진은 JPG/JPEG/PNG, 여러 장 합계 5MB까지 업로드할 수 있습니다.

7. 실행이 안 될 때
python 명령이 없으면 Python 설치와 PATH 설정을 확인합니다.
python 대신 py 명령이 동작하면 위 명령의 python을 py로 바꿔 실행합니다.
라이브러리 오류가 나면 2번 설치 명령을 다시 실행합니다.
서버가 실행된 터미널은 사용하는 동안 열어 둡니다.
